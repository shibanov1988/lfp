# Конвенции для этого репозитория

- При каждом изменении конфигурации (любой коммит, меняющий что-то в `src/`)
  увеличивать версию релиза в `src/Configuration.xml` — свойство
  `Configuration/Properties/Version` (сейчас `1.0.1`). Увеличивать patch-часть
  (последнее число), например `1.0.1` → `1.0.2`.
